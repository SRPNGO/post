> "7月19日，本站子站点(oc.srpn.top)正式上线，站长为Nsakrty，并将星球阁非官方立场的文章整理于此。这助推了星球阁网站生态内容的多元化和立场的丰富性，有助于对星球阁的进一步了解。24日，水益正式成为其编辑。"
>

该站点与主站 srpn.top 在叙事定位上明确区分：主站承载官方叙事，子站点承载更深入、更接近原始资料的非官方记录。7月29日，星球阁官网与该文档汇总站一同开始使用流量统计功能。

## 技术架构

星球阁非官方文档站基于 GitHub Pages 部署，采用 Jekyll 静态站点生成器与 Kramdown Markdown 引擎渲染。站点内容以 Markdown/HTML 文件存放于仓库的 `docs/`（文档）与 `wiki/`（词条）目录，并通过 GitHub Actions（jekyll-gh-pages.yml）自动构建发布。其Wiki板块的索引、互链与分类依赖 `scripts/` 目录下的一套自动化流程脚本（详见[星球阁Wiki](/wiki/srpnWiki)条目）。

## 与相关站点的关系

- **与SRPN网（主站）**：[SRPN网](/wiki/srpnSite)是星球阁的官网，承载官方叙事；非官方文档站是其子站点，收录官方叙事之外、更接近原始资料的记录，二者在首页互相提供入口。

- **与星球阁存档计划**：本站文档与非官方文章的整理方向与存档计划的资料体系互补，共同扩充[星球圈](/wiki/SC)资料的广度。
